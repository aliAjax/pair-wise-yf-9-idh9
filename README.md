# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 共享规则

同一系列桌游的通用规则只需维护一份，不必逐款复制：

- 在左侧"共享规则"面板新增规则，每条选择一个分类并勾选适用的游戏。
- 游戏详情仍按"容易忘的规则 / 常见争议 / 开局准备 / 计分提醒"四类顺序展示，共享内容会标注来源。
- 游戏可以"改写"共享内容；共享规则更新后，改写版保留并标记"待确认"，核对后手动解除。
- 移除共享规则时，各游戏保留当前实际生效的文字，转为本地规则。
- 搜索与统计按各游戏实际生效的内容计算，同一共享规则在一款游戏里只算一次。

## 代码结构

共享规则的存档、引用判定和页面展示分开维护：

- `shared-store.js`：共享规则存档（数据结构、增删改、改写与待确认标记）。
- `shared-resolver.js`：引用判定（计算每款游戏实际生效的规则内容）。
- `app.js`：页面展示与交互。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
