# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 共享规则

同一系列桌游的通用规则只需在「共享规则库」维护一份：

- 每条共享规则选择**一个分类**（容易忘的规则 / 常见争议 / 开局准备 / 计分提醒），并勾选**适用游戏**；
- 游戏详情按原有四类顺序展示，共享条目带「共享」标记排在本类前面，游戏自己的本地条目排在后面；
- 每款游戏可以把共享内容**改写**成自己的版本（「改写」标记）；
- 共享规则原文更新时，未改写的游戏直接看到新版；已改写的游戏**保留改写文字**并标红「待确认」，核对时可选「保留改写」（标记解除）或「采用新版」（放弃改写）；
- 删除共享规则或取消勾选某款游戏时，该游戏**保留当前生效文字**并固化为本地规则；
- 搜索和顶部遗忘点统计都按**实际生效内容**计算，同一条共享规则在一款游戏里只计一次。

代码按三层分开维护：`app.js` 顶部是共享规则存档（`shared` / `overrides` 数据与增删改），中间是引用判定（`resolveGame` / `getEffectiveRules` 等纯函数，决定每款游戏实际生效的内容），底部是页面展示（渲染与事件）。
